## プロジェクト概要

SalesforceとMoneyForwardの手動データ連携を完全自動化。営業事務チームの見積書・請求書発行時間を月13時間削減し、ヒューマンエラーをゼロにした事例です。

## 課題の詳細

### 手動データ入力の問題点

**時間的コスト**
- 月50件の見積書・請求書発行
- 1件あたり15分の手動入力
- **年間150時間の非効率作業**

**品質の問題**
- 月7.5件のヒューマンエラー（入力ミス）
- Salesforce・MoneyForward間のデータ不整合
- 顧客情報の二重管理による混乱

**ビジネスへの影響**
- 請求書発行の遅延
- 顧客からの信頼低下リスク
- 営業事務の業務負荷増大

## 実施した施策

### システムアーキテクチャ

```
[Salesforce] ←→ [Google Apps Script] ←→ [MoneyForward]
                        ↓
              [Google Sheets]
           (管理・ログ・設定)
```

### 主要機能

**1. 顧客情報の自動同期**
- **完全同期**（月次実行）: 全顧客データの一括同期
- **増分同期**（日次実行）: 新規・更新データのみ同期
- **双方向ID連携**: SalesforceとMoneyForwardのIDを紐付け管理

**2. 請求書自動発行**
- **一括処理**: 月50件を自動処理
- **税率自動変換**: システム間の税率形式差を自動調整
- **リアルタイム進捗表示**: 処理状況の可視化

**3. データ管理**
- **変更履歴の完全記録**: 誰が・いつ・何を変更したか追跡
- **エラーログ分析**: 問題発生時の詳細ログ
- **削除候補管理**: MoneyForward上の不要データ検知

### セキュリティ対策

- **OAuth 2.0認証**: 安全な認証フロー
- **HTTPS暗号化通信**: データ転送の保護
- **アクセス権限制御**: 最小権限の原則

## 導入プロセス

### フェーズ1: 現状分析（1週間）
